# Jatin & Tanvi — Wedding Invitation

A scroll-scrubbed invitation: six clay-diorama scenes (Welcome, Haldi, Mehendi, DJ Night, Baraat, Wedding) joined by connector fly-overs.

- `index.html` — page, copy and scene config
- `scrub-engine.js` — scroll-scrub engine
- `assets/` — encoded clips and poster stills
- `work/` — prompts and build scripts (raw renders are not committed)

Run locally: `python3 -m http.server 8912` and open http://localhost:8912/
